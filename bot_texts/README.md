## bot_texts

مجموعة ملفات JSON منظَّمة لكتابات البوت (بالعربية) مع إضافة إيموجيات طبية مثل 🧬💊🌡️🩹🫁🧠🦠🔭🩺🔬🗜️.

### البنية
```
bot_texts/
  shared/
    emojis.json        # مرجع سريع للإيموجيات الطبية
  admin/
    main_menu.json     # قائمة لوحة الإدارة
    flows/
      add_subject.json             # إضافة مادة
      add_case_or_question.json    # إضافة حالة مرضية أو سؤال
      delete.json                  # الحذف (مادة/حالة/سؤال)
      join_requests.json           # طلبات الانضمام للبوت
  user/
    first_time.json     # ما يراه المستخدم قبل قبوله
    after_approval.json # شاشة المستخدم بعد القبول وخياراته
    display_formats.json# أشكال الرسائل النهائية للحالات والأسئلة
```

### طريقة التعديل
- افتح أي ملف JSON وعدّل النصوص مباشرة. كل عنصر مصاغ كسلاسل نصية جاهزة للعرض في البوت.
- تم إدراج الإيموجيات داخل النصوص لسهولة القراءة. يمكنك نسخ أي رمز من `shared/emojis.json`.
- حافظ على صياغة المفاتيح لتبقى البنية متناسقة، لكن أسماء المفاتيح ليست إلزامية للتشغيل إن كنت ستقرأ النصوص يدوياً.

### ملاحظات تربط مع المخطط
- ملفات `admin/*` تقابل لقطات لوحة الأدمن في المخطط: إضافة مادة، إضافة حالة/سؤال، الحذف، طلبات الانضمام.
- ملفات `user/*` تقابل واجهة المستخدم: أول استخدام، بعد القبول، وصيغ العرض النهائية.
- جميع النصوص مزودة بإيموجيات طبية لتوضيح السياق: الأعراض 🌡️، الفحوصات 🔬، التشخيص 🧠، العلاج 💊، إلخ.

### اقتراحات لاحقة
- إن رغبت في توليد الواجهات تلقائياً، استخدم هذه الملفات كمصدر نصوص، مع ربط خيارات `menu` و`steps` بالأزرار.
- يمكن لاحقاً فصل نصوص كل مادة في ملف خاص إذا كبرت البيانات.
